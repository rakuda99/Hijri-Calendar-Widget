## 🎨 عالم التخصيص الكامل / Extreme Customization

صُمم هذا التطبيق بمبدأ واحد: **"هاتفك.. ذوقك.. شاشتك"**. على عكس التطبيقات المغلقة التي تفرض عليك تصميماً ثابتاً، يتيح لك هذا التطبيق لوحة تحكم كاملة للتحكم في كل عنصر على حدة:

### 1️⃣ تخصيص ودجت الساعة والتقويم (Clock & Calendar Customization):
- 👁️ **إظهار أو إخفاء أي عنصر (Visibility Toggles):**
  - إظهار/إخفاء الساعة الرقمية.
  - إظهار/إخفاء التاريخ الهجري.
  - إظهار/إخفاء التاريخ الميلادي.
  - إظهار/إخفاء اسم المدينة الحالية.
  - إظهار/إخفاء درجة الحرارة والطقس.
  - إظهار/إخفاء رموز التمييز (رمز **هـ** للتاريخ الهجري ورمز **م** للميلادي).
- 🔤 **التحكم بمقاسات الخطوط (Font Sizes):**
  - اختيار مقاس خط الساعة من بين 5 مقاسات مدروسة (من الصغير إلى العملاق البارز).
  - اختيار مقاس خط التاريخ الهجري بشكل منفصل.
  - اختيار مقاس خط التاريخ الميلادي بشكل مستقل.
  - خيار تفعيل التسميات الكبيرة للوقت (Large Time Labels).
- 🎨 **تلوين مستقل لكل عنصر (Independent Color Engine):**
  - لون مخصص لأرقام الساعة.
  - لون مخصص لنص التاريخ الهجري.
  - لون مخصص لنص التاريخ الميلادي.
  - لون مخصص لاسم اليوم (السبت، الأحد..).
- 📆 **طريقة وموضع عرض اسم اليوم (Day Layout & Orientation):**
  - عرض اليوم بشكل **أفقي** أو **عمودي رأسي**.
  - موضع اليوم: وضعه على **يمين الساعة** أو **يسار الساعة**.
  - لغة اليوم: باللغة العربية، الإنجليزية، أو **كلاهما معاً** في نفس الوقت.
- 🕒 **أنماط الوقت والأرقام:**
  - التحويل بين نظام 12 ساعة ونظام 24 ساعة.
  - عرض (صباحاً / مساءً) بالأحرف العربية (ص / م) أو الإنجليزية (AM / PM).
  - التبديل الفوري بين الأرقام العربية-الهندية (١، ٢، ٣) والأرقام الغربية (1, 2, 3).
- 🖼️ **خلفيات مخصصة للودجت:**
  - خلفية شفافة بالكامل (Transparent) لتندمج مع خلفية الشاشة.
  - خلفية سوداء معتمة مصممة لشاشات AMOLED لتوفير الطاقة.
  - خلفيات شبه شفافة (Dark/Light Frost) أو بيضاء ناصعة.

### 2️⃣ تخصيص ودجت مواقيت الصلاة (Prayer Widget Customization):
- 🎛️ **أنماط العرض المتعددة:**
  - **شريط أفقي مدمج (Horizontal Grid):** يعرض الصلوات الخمس بالتتالي مع تمييز الصلاة القادمة.
  - **قائمة رأسية تفصيلية (Vertical List):** مناسبة للشاشات الكبيرة وأعمدة الشاشة الرئيسية.
  - **نمط الصلاة القادمة فقط (Next Prayer Prominent):** كرت كبير يبرز الصلاة التالية فقط ووقتها والعد التنازلي لها.
  - **نمط العداد التنازلي فقط (Remaining Countdown Only):** سطر أنيق ومقتضب يعرض كم بقي على الأذان فقط.
- 👁️ **تحكم مرن بالظهور:**
  - إظهار أو إخفاء وقت الشروق.
  - إظهار أو إخفاء أرقام أوقات الصلوات والاكتفاء بالأسماء.
  - إظهار أو إخفاء الساعة داخل ودجت الصلاة.
- 🌟 **تخصيص ألوان التمييز للصلاة النشطة (Active Prayer Highlights):**
  - تمييز الصلاة الحالية بخلفية ذهبية كاملة (Golden Solid) أو إطار ذهبي أنيق (Golden Stroke).
  - إطارات بيضاء، حمراء، أو فيروزية (Teal Stroke).
  - تمييز وقت الأذان (Adhan Alert Window) بتحول الصلاة النشطة إلى اللون الأحمر تلقائياً قبل الأذان بـ 5 دقائق وحتى 20 دقيقة بعده.
- 📐 **أحجام خطوط الصلاة:** مقاسات مخصصة لأسماء الصلوات ومقاسات مخصصة لأرقام الأوقات.
- 🪟 **أنماط الخلفيات:** خلفية زجاجية فاخرة (Glassmorphism)، تدرج لوني (Gradient)، شفاف، أو ألوان صلبة.

### 3️⃣ ودجت تقويم الشهر الهجري (Hijri Month Calendar Widget):
- 📅 **شبكة تقويم كاملة:** تعرض جميع أيام الشهر الهجري مع تمييز دقيق لليوم الحالي.
- 🔄 **تصفح مرن:** أزرار للتنقل بين الشهور الهجرية القادمة والسابقة مباشرة من الشاشة.
- 🕌 **تمييز أيام الجمعة:** تمييز بصري خاص لأيام الجمعة وبدايات الشهور.
- 🎨 **تخصيص كامل للألوان:** تخصيص ألوان أرقام الأيام، الهيدر، واليوم المختار.

## 📖 ماذا يقدم البرنامج وفكرته الأساسية؟ / What It Does

بالإضافة للتخصيص الشامل، يقوم التطبيق بوظيفته الأساسية على أكمل وجه وبأعلى درجات الدقة والموثوقية:

1. **نظرة واحدة تغنيك عن فتح التطبيقات:**
   كل ما يحتاجه يومك كمسلم (الساعة، التاريخ الهجري اليومي، التاريخ الميلادي، وقت الصلاة القادمة، كم دقيقة بقيت، اسم مدينتك) حاضر أمامك في ودجت أنيق يتناغم مع خلفية هاتفك.
2. **كشف السفر التلقائي (Smart Travel Detection):**
   عند الانتقال أو السفر لمسافة تتجاوز 5 كم (مثل السفر من جدة إلى الرياض أو العكس)، يكتشف التطبيق تغير الإحداثيات، ويمسح الكاش فوراً، ويعيد حساب مواقيت الصلاة لمدينتك الجديدة دون أي تدخل يدوي منك.
3. **محرك حساب فلكي مدمج (100% Offline):**
   لا يتطلب التطبيق اتصالاً بالإنترنت لحساب مواقيت الصلاة أو التاريخ الهجري. الحسابات تتم محلياً بالكامل بدقة متناهية وفق مختلف الهيئات الفلكية (أم القرى، رابطة العالم الإسلامي، الهيئة العامة المصرية، إلخ).
4. **تحديث فوري عند منتصف الليل:**
   تمت هندسة التطبيق ليتغلب على قيود توفير الطاقة في أندرويد (Doze Mode)، حيث ينقل التاريخين الهجري والميلادي فور دخول الساعة 12:00 ليلاً بدقة ثانية.

## ⚙️ المعمارية الفنية / Technical Architecture

- **UI Framework:** Android AppWidget Framework (`RemoteViews`) متوافق مع Android 8.0 (API 26) وحتى Android 14+ (API 34).
- **Calculation Engine:** محرك الحسابات الفلكية المعتمد والمدمج محلياً (`Offline Prayer Engine`) مع دعم خيارات فقهية (مذهب العصر الشافعي والحنفي).
- **Location & Geofencing:** استخدام `LocationManager` مدمج مع معادلة حساب المسافة الجغرافية الكروية (Haversine Formula) لرصد حركة السفر بدقة 5 كم.
- **Smart Cache:** نظام كاش ذكي (`CacheManager`) يفصل بين التاريخ، مواقيت الصلاة، والموقع لتسريع رسم الودجت بنسبة 100%.

## 🚀 طريقة التثبيت والبناء / How to Build

### المتطلبات الأساسية:
- **Android Studio** (Hedgehog أو أحدث)
- **JDK 17** أو JDK 11
- **Android SDK:** API 26+ (Target: API 34)

### خطوات البناء:
```bash
# 1. استنساخ المستودع
git clone https://github.com/rakuda99/Hijri-Calendar-Widget.git
cd Hijri-Calendar-Widget

# 2. بناء ملف التجربة (Debug APK)
./gradlew assembleDebug

# 3. التثبيت المباشر على الهاتف المتصل عبر ADB
./gradlew installDebug
```
