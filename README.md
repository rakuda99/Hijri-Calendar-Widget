## 📖 ماذا يقدم البرنامج وفكرته؟ / What It Does

كثير من المستخدمين المسلمين يواجهون مشكلتين رئيسيتين مع تطبيقات التقويم والمواقيت التقليدية:
1. **الاضطرار لفتح التطبيق كل مرة** لمعرفة كم بقي على أذان الصلاة القادمة أو لمطابقة التاريخ الهجري مع الميلادي.
2. **استنزاف البطارية أو الخطأ عند السفر** حيث تفشل الكثير من الودجتات في تحديث المدينة عند الانتقال من مكان لآخر، أو تتوقف عن التحديث عند منتصف الليل بسبب أوضاع توفير الطاقة في أندرويد (Doze Mode).

### 💡 الحل الذي يقدمه هذا التطبيق:
هذا البرنامج هو **ودجت شاشة متكامل (Home Screen Widget)** مصمم ليعمل بهدوء في الواجهة:
- **نظرة واحدة تكفي:** بمجرد فتح قفل الهاتف، يظهر لك الوقت بدقة، التاريخ الهجري اليومي والميلادي، واسم المدينة الحالية، والوقت المتبقي حتى الصلاة القادمة (مثلاً: *بقي: 18 دقيقة على صلاة العصر*).
- **يتكيف مع تنقلاتك وسفرك تلقائياً:** بمجرد انتقالك من مدينة إلى أخرى (مسافة أكثر من 5 كم)، يتعرف الودجت على موقعك الجديد ويعيد حساب مواقيت الصلاة للمدينة الجديدة فوراً.
- **يعمل 100% بدون إنترنت:** يحتوي التطبيق على محرك حسابات فلكية مدمج، مما يعني أن مواقيت الصلاة والتاريخ الهجري تعمل دائماً بدقة حتى في أوقات انقطاع الشبكة أو السفر في البر.
- **تحديث فوري عند منتصف الليل:** يضمن أن التاريخ الهجري والميلادي ينتقلان إلى اليوم الجديد بدقة ثانية بلحظة دخول الساعة 12:00 ليلاً دون أي تأخير.

## ✨ المميزات الرئيسية / Key Features

- 📅 **تقويم هجري وميلادي متزامن:** عرض اليوم والتاريخ الهجري والميلادي معاً بتنسيقات متعددة وإمكانية تعديل التاريخ الهجري يدوياً (+1 / -1 يوم) لمطابقة الرؤية الشرعية.
- 🕌 **مواقيت الصلوات الخمس + الشروق:** حساب فلكي دقيق حسب تقويم أم القرى، رابطة العالم الإسلامي، الهيئة المصرية، وغيرها.
- ⏳ **عداد تنازلي ذكي للصلاة:** إبراز الصلاة القادمة بلون مميز مع بيان الوقت المتبقي بالساعات والدقائق، والتنبيه بدخول وقت الصلاة.
- ✈️ **نظام كشف السفر الذكي (Travel Detection):** مقارنة الإحداثيات عبر الـ GPS؛ إذا ابتعدت مسافة > 5 كم يقوم الودجت بمسح الكاش القديم وتحديث مواقيت المدينة الجديدة تلقائياً.
- 📍 **مؤشر اسم المدينة الحالية:** يعرض اسم المدينة التي تستخدمها الحسابات تحت الساعة لتكون على دراية تامة بموقعك.
- 🔋 **استهلاك بطارية شبه منعدم:** التطبيق لا يحتوي على خدمات مستمرة (Services) تستهلك المعالج في الخلفية، بل يعتمد على نظام تنبيهات الأندرويد المجدولة بدقة (`AlarmManager`).
- 🎨 **تخصيص كامل للشكل والألوان:**
  - دعم المظهر الداكن الشديد لشاشات AMOLED.
  - خيارات تلوين مخصصة للساعة، التاريخ، ومواقيت الصلاة.
  - إمكانية الاختيار بين الأرقام العربية (١، ٢، ٣) أو الإنجليزية (1, 2, 3).
- 🌐 **دعم كامل للغتين:** العربية والإنجليزية بشكل افتراضي مع سهولة التبديل بينهما.

## 📱 الودجتات المتاحة / Available Widgets

يوفر التطبيق 4 خيارات للودجت لتناسب جميع أحجام الشاشات وتفضيلات المستخدم:

| الودجت | الحجم المقترح | الوصف ومحتويات العرض |
| :--- | :---: | :--- |
| **ودجت التقويم والساعة الرئيسية** | 4x2 أو 3x2 | الساعة الرقمية الكبيرة، اسم اليوم، التاريخ الهجري، التاريخ الميلادي، المدينة الحالية، ودرجة الحرارة. |
| **ودجت شريط الصلاة الأفقي** | 4x1 أو 5x1 | شريط يعرض الصلوات الخمس بالتوالي مع تمييز الصلاة القادمة والوقت المتبقي. |
| **ودجت الصلاة الرأسي القائم** | 2x3 أو 2x4 | جدول رأسي يعرض مواقيت اليوم بالكامل مع أسماء الصلوات وحالتها. |
| **ودجت الشهر الهجري الكامل** | 4x3 أو 4x4 | تقويم يعرض شبكة أيام الشهر الهجري كاملاً مع تمييز اليوم الحالي وأيام الجمعة. |

## ⚙️ المعمارية الفنية / Technical Architecture

- **UI Framework:** Android AppWidget Framework (`RemoteViews`) متوافق مع Android 8.0 (API 26) وحتى Android 14+ (API 34).
- **Calculation Engine:** محرك الحسابات الفلكية المعتمد والمدمج محلياً (`Offline Prayer Engine`).
- **Location & Geofencing:** استخدام `LocationManager` مدمج مع معادلة حساب المسافة الجغرافية الكروية (Haversine Formula) لرصد حركة السفر بدقة 5 كم.
- **Smart Cache:** نظام كاش ذكي (`CacheManager`) يفصل بين التاريخ، مواقيت الصلاة، والموقع لتسريع رسم الودجت بنسبة 100%.

## 🚀 طريقة التثبيت والبناء / How to Build

### المتطلبات الأساسية:
- **Android Studio** (Hedgehog أو أحدث)
- **JDK 17** أو JDK 11
- **Android SDK:** API 26+ (Target: API 34)

### خطوات البناء:
```bash
# 1. استنساخ المستودع
git clone https://github.com/rakuda99/Hijri-Calendar-Widget.git
cd Hijri-Calendar-Widget

# 2. بناء ملف التجربة (Debug APK)
./gradlew assembleDebug

# 3. التثبيت المباشر على الهاتف المتصل عبر ADB
./gradlew installDebug
```
